产品合同

  • 打招呼 ≠ 完成开心：wave 举手 + 头顶 tip；happy 安静笑 + 既有结果反馈。
  • 桌面与小窝共用同一套 tip（「你好」）与同一 wave 姿态，降低维护成本。
  • V0 不做序列帧；挥动由 SpriteKit 对抬爪臂做轻量旋转（约两下）。
  • Reduce Motion：定格 hold，不挥，tip 仍可出现。

工程接入（验收后）

  • 把 j-arms-wave / joey-wave 并入 joeypet-states-v0.html 姿态板。
  • build_joey_pose_assets.py 拆出 arm.backWave / arm.frontWave。
  • manifest 增加 pose wave；greeting 映射到 wave，不再复用 happy。

验收清单

  1. 缩略图下抬起的右爪仍然可读。
  2. 脸是 happy（弯眼笑），不是 calm 睁眼。
  3. 左臂明显休息；无木牌、叶子、文字、气泡进像素。
  4. 落脚与 sit 接触线一致（y≈388）；整身不抬跳。
  5. 和 happy / sign / stretch 一眼能分。
